
2) Écrivez un programme pour compter le nombre de nombres pair et impairs dans un séquence donnée (liste) dans le fichier ex2.py

3) Afficher les nombres impairs de 1 à 100 sur une même ligne, sauf les multiples de 7; utilisez ``continue`` et le bon range()

4) Petit classique:  Affichez les termes la suite de fibonacci dont la valeur est plus petite que 150. Petit rappel: le terme de la suite fibonacci est la somme des deux termes précédents : i.e. 0 1 1 2 3 5 8 13...
